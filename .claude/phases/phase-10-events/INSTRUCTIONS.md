## Proposed System

### Event Types
- Private parties
- Corporate events
- Special occasions
- One-time cooking sessions

### Booking Flow
```
Event Inquiry Form
    → GHL Contact Created
    → GHL Opportunity (Events Pipeline)
    → Quote/Proposal Sent
    → Agreement Signed
    → Deposit Collected
    → Event Confirmed
    → Chef Assigned
    → Event Completed
    → Follow-up/Review Request
```

---

## Components Needed

1. **Event Inquiry Form** - Capture event details
2. **Events Pipeline in GHL** - Separate from client onboarding
3. **Quote/Proposal System** - Pricing calculator or templates
4. **Event Agreement Template** - SignWell
5. **Deposit Collection** - QuickBooks invoice
6. **Chef Assignment** - Based on availability + event type
7. **Post-Event Follow-up** - Review request automation
