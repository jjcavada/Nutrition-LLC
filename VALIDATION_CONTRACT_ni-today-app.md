## Design
- **Data (read):** GoHighLevel API v2 with the Private Integration Token, server-side only (Netlify function `api`), never in the browser.
  Opportunities in pipeline t6tPDiRCfcKiVr7vUkxW (stage + Assigned Chef `a92gzVh8Ukz7gkvRKf03` via GET /opportunities/{id}),
  contacts (`GET /contacts/?locationId`: tags, phone, email, custom fields), calendar events for user FXhRBT40lYMaDBbHEEmJ
  (weekly wtbOuayfIZ6DycweJDSE / event vj3iEVtjT9BNAnlUhKcW), notes on demand. Snapshot cached 2 minutes server-side; the phone keeps the
  last snapshot offline.
- **Per-contact fields (written by Make, read by the app):** Drive Folder, Drive Folder ID, Client List Row, Signed Document ID (from the
  Drive scenario) plus, new today: Intake PDF, Contract PDF, Intake Note ID, Intake Summary (OpenAI, generated in Make scenario 6561132
  v2.2 on intake; backfilled once for existing clients with `event=summary`).
- **Client stages shown:** New lead = pipeline stage New Lead (intake received, agreement not signed). Waiting for a chef = signed or
  further along AND Assigned Chef empty or `tbd`. Active = Assigned Chef set. Abandoned/lost hidden.
- **Chef dropdown:** POSTs `{contactId, chefName, clientName, source: "NI Today app"}` to Make 6116697 (hook 2759192, the same hook the
  Google Sheet uses). 200 `sent` = chef emailed + Assigned Chef written + CRM note (by 6116697). 409 `no-menu` shown as a plain message.
- **Calls:** calendar events today and the next 7 days, labeled by calendar id (weekly / event), tap = the contact's intake summary,
  allergies, where they came from (tags: intake_received / event_inquiry / referral text), phone, call/text buttons.
- **Passcode:** 6 digits chosen by Amber (temporary code set by Jay). Browser sends sha256(salt + code); the function compares to the
  stored hash and rejects everything else. Lock screen on open; remembered on the device until she locks it.
- **Push:** service worker + VAPID (existing keys); subscriptions stored in Netlify Blobs; `POST /api/notify` (shared secret) called
  by Make 6561132 route A (new intake) and route C (signed agreement).
- **Alerts:** every Make change keeps GR-002 (alert + Resume/Commit). The app shows a visible "could not load" state, never a blank page.
